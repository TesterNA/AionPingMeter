## Чому AionPingMeter?

Більшість програм для пінгу або показують число, яке поступово «відпливає» від реальності, або перевіряють з'єднання раз на кілька секунд і пропускають саме ті лаги, які ти відчуваєш. AionPingMeter працює інакше:

| | |
|---|---|
| 🔓 **Відкритий код: нічого не приховано** | Програма, яка читає твій мережевий трафік, не має бути «чорною скринькою». Увесь код AionPingMeter відкритий: кожен може подивитися, що саме вона робить, переконатися, що вона нічого нікуди не відправляє, і зібрати її самостійно. Уся програма — один зрозумілий файл, [`Program.cs`](Program.cs). |
| 🎯 **Міряє так само, як сама гра** | AionPingMeter читає власний обмін ping між грою і сервером, той самий, яким користується клієнт. Ти бачиш реальну затримку гри, а не здогадку за іншим з'єднанням. |
| ⏱️ **Один годинник, жодного дрейфу** | Час відправки й отримання береться з того самого апаратного таймера, що й у гри. Корекції годинника Windows, синхронізація часу й довгі сесії не додадуть приховані +100 мс, які потім не зникають. Через 8 годин число таке ж точне, як через 8 секунд. |
| 🔍 **Показує, *де* лаг** | Кожен стрибок розкладається на **ПК → мережа → сервер**, тож одразу ясно, кого винити: Wi-Fi, провайдера чи гру. |
| 🧊 **Ловить лаги між замірами** | Гра міряє пінг лише раз на ~10 с. AionPingMeter додатково постійно стежить за потоком оновлень сервера (20 разів на секунду) і за мережевою затримкою, тож короткі фризи й стрибки не проходять непомітно. |
| 📉 **Помічає втрату пакетів** | Загублені й повторно відправлені пакети на ігровому з'єднанні виявляються навіть тоді, коли пінг виглядає нормально. |
| 🪶 **Легкий** | ~180 КБ, близько 0,005 % CPU і ~11 МБ пам'яті. Мережевий драйвер передає програмі лише пакети гри й ігнорує решту трафіку. |
| 🔒 **Лише читає, нічого не відправляє** | Нічого не інжектиться в гру, файли гри не змінюються, і AionPingMeter **нікуди нічого не відправляє**. Жодних акаунтів, телеметрії чи перевірок оновлень. |
| 🔄 **Без налаштувань** | Сам знаходить гру, мережевий адаптер і потрібне з'єднання з сервером і не губить їх при перезаході, перенесенні персонажа, перемиканні Wi-Fi ↔ кабель чи VPN. |

## Що показує оверлей

```
38 ms              max 39      ← пінг у грі · максимум за останню хвилину
network 18                     ← чиста мережева затримка, оновлюється постійно
```

| Значення | Що означає |
|---|---|
| **ms** (велике число) | **Пінг у грі**: час від запиту твого клієнта до відповіді сервера. Сюди входить дорога туди й назад **плюс** час, поки сервер обробить запит. Саме це ти відчуваєш у грі. |
| **max** | Найбільший пінг у грі за останню хвилину. |
| **network** | **Чиста мережева затримка** до сервера гри, без обробки на сервері. Оновлюється кілька разів на секунду. |

> **Варто знати:** `ms` завжди більше за `network`. Різниця — це час реакції сервера (сервери Aion 2 працюють тактами по 50 мс). Якщо `network` стабільна, а `ms` стрибає, проблема на боці сервера, а не в тебе.

Число зелене 🟢 до 60 мс, жовте 🟡 до 120 мс і червоне 🔴 вище.

## Попередження про лаги

Коли щось іде не так, з'являється третій рядок з усім, що сталося за останню хвилину:

<div align="center">
  <img src="docs/overlay-alert.png" alt="Приклад попередження" />
</div>

```
⚠ ping 1200 (server) · network 60 · freeze 450 · loss ×2 · 15s ago
```

| Попередження | Що сталося |
|---|---|
| `ping 1200 (server)` | Стрибнув пінг у грі. У дужках видно, де загубився час: **(server)** — сервер, **(network)** — мережа, **(PC)** — твій ПК. |
| `network 60` | Зв'язок із сервером став повільнішим. |
| `freeze 450` | Сервер 450 мс не надсилав оновлень. Це фриз на боці сервера, навіть якщо мережа ідеальна. |
| `loss ×2` | Пакети загубились і їх довелося відправити повторно. Зазвичай відчувається як мікрофриз. |

- **Перші 10 секунд:** рядок **червоний**, навколо оверлею червона рамка, іконка в треї теж червона.
- **До хвилини:** рядок **помаранчевий**, щоб було видно, що проблема була *нещодавно*.
- **Потім:** зникає сам.

Поточний пінг і мережа весь цей час лишаються на екрані.

### Швидка діагностика

| Бачиш… | Найімовірніша причина |
|---|---|
| `freeze` або `ping (server)`, мережа стабільна | Збій сервера гри чи шлюзу. З твого боку нічого виправляти не треба. |
| `network` та/або `loss` | Wi-Fi, роутер, провайдер або маршрут до сервера. |
| `ping (PC)` | Комп'ютер затримав запит, наприклад через навантаження на процесор чи диск. |
| Лаг відчувся, а **попереджень немає** | Локальне підвисання (просідання FPS). Сервер і мережа працювали нормально. |

## Встановлення

### Який файл завантажити?

Кожен [реліз](../../releases/latest) має дві версії. Працюють вони однаково:

| Файл | Розмір | Для кого |
|---|---|---|
| **`AionPingMeter-vX.Y.Z-standalone.zip`** | десятки МБ | 👍 **Рекомендовано. Не впевнений — бери цей.** Усе вже всередині, нічого додатково встановлювати не треба. |
| **`AionPingMeter-vX.Y.Z-light.zip`** | ~0,2 МБ | Легка версія для тих, у кого вже встановлено [.NET 8 Desktop Runtime (x64)](https://dotnet.microsoft.com/download/dotnet/8.0). Без нього програма не запуститься. |

### Що потрібно

- Windows 10 / 11 (64-bit)
- [**Npcap**](https://npcap.com/#download) (безкоштовний), потрібен **обом** версіям. Якщо ти вже користуєшся іншим мережевим метром, він, найімовірніше, встановлений.
  Під час встановлення **не став** галочку **«Restrict Npcap driver's access to Administrators only»**.
- [**.NET 8 Desktop Runtime**](https://dotnet.microsoft.com/download/dotnet/8.0) (x64): **лише для легкої версії**.

### Запуск

1. Завантаж обраний архів з [останнього релізу](../../releases/latest).
2. Розпакуй у будь-яку папку, наприклад `C:\Games\AionPingMeter`.
3. Запусти `AionPingMeter.exe`. Права адміністратора не потрібні.
4. Запусти Aion 2. Оверлей заповниться сам протягом ~10 секунд після входу у світ.

> Windows SmartScreen може попередити про невідомого видавця, бо програма не має цифрового підпису. Натисни **Докладніше → Виконати однаково**.

**Оновлення:** закрий AionPingMeter через трей, розпакуй нову версію поверх старої й запусти знову. Налаштування збережуться.

**Видалення:** видали папку з програмою і за бажанням `%APPDATA%\AionPingMeter` (налаштування й логи).

## Меню в треї

Клацни правою кнопкою по іконці AionPingMeter біля годинника. Якщо її не видно, зазирни під стрілку **^** з прихованими іконками.

| Пункт | Що робить |
|---|---|
| **Server: x.x.x.x:port** | Шлюз гри, до якого ти підключений. Клік копіює адресу, щоб порівняти з друзями. |
| **Show server in overlay** | Додає адресу шлюзу окремим рядком в оверлей. |
| **Move** / **Lock position** | Розблокувати оверлей, перетягнути куди завгодно й закріпити. Позиція запам'ятовується. |
| **Reset position** | Повертає оверлей у лівий верхній кут основного монітора. |
| **Write log** | Записує кожен замір у CSV-файл (див. нижче). |
| **Alert threshold** | Пінг, вище якого попередження з'являється завжди: 80 / 100 / 150 / 200 / 300 мс. Різкі стрибки позначаються незалежно від порогу. |
| **Exit** | Закриває AionPingMeter. |

**Наведи мишку** на іконку в треї, щоб побачити лічильники за сесію:

```
AionPingMeter · 203.0.113.42:12000
pings 412 · loss 0 · freeze 1
gateway changes 0
```

Іконка в треї теж змінює колір (сіра / зелена / жовта / червона), тож стан з'єднання видно, навіть коли оверлей схований.

Оверлей ніколи не перехоплює фокус і пропускає всі кліки в гру.

## Лог

Якщо ввімкнено **Write log**, AionPingMeter дописує заміри у файл:

```
%APPDATA%\AionPingMeter\ping-log.csv
```

```csv
time,ping_ms,pc_ms,network_ms,server_ms,gateway
2026-01-15 20:31:04.512,39.4,1.0,19.0,19.4,203.0.113.42:12000
2026-01-15 20:31:15.268,freeze,4290,,,,203.0.113.42:12000
2026-01-15 20:31:15.341,863.9,1.0,18.9,844.0,203.0.113.42:12000
```

Лог відкривається в Excel чи Google Sheets. Він допомагає помітити закономірності, наприклад лаги в години пік чи на конкретному шлюзі, і підкріпити звернення в підтримку точним часом.

## Часті питання

**Чи можуть за це забанити?**
AionPingMeter лише *спостерігає* за мережевим трафіком, так само як Wireshark. Він не чіпає процес гри, її пам'ять чи файли і не змінює й не відправляє жодних пакетів. Утім, сторонні програми завжди використовуються на власний розсуд.

**Чи працює на серверах Кореї / Тайваню?**
Поки що ні. У цих регіонах інший формат міток часу, тож оверлей показуватиме `—`. Підтримується Global (EU/NA).

**Чи працює з VPN або прискорювачем для ігор?**
Так. AionPingMeter стежить за з'єднанням гри, хоч би через який адаптер воно йшло.

**Оверлей показує `— ms`.**
Перевір, що Npcap встановлено, гра запущена і ти вже у світі. Перше значення з'явиться з наступним ping гри, приблизно за 10 секунд.

**Чому пінг у грі приблизно на 20 мс більший за `network`?**
Це час обробки на сервері. Сервер обробляє запити тактами по 50 мс, тож запит чекає своєї черги від 0 до 50 мс. Це нормально й однаково для всіх.

**У друзів був лаг, а в мене ні, хоча ми були в одному місці. Як так?**
Гравців часто обслуговують різні шлюзи. Порівняйте адресу **Server** у меню трею: якщо у друзів вона інша, то застиг їхній шлюз, а не вся гра.

## Збирання з коду

Потрібен [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).

```
git clone <цей репозиторій>
cd AionPingMeter
dotnet build -c Release -o out
```

Готова програма буде в `out\AionPingMeter.exe`. Уся програма — один файл, [`Program.cs`](Program.cs).
